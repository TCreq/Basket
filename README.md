# Basket
Dans ce Repository, j'ai déposé l'ensemble des fichiers de ma contributuion pour le test technique pour MP Data.

Vous trouverez plusieurs fichiers de code Python et notebooks pour détailler mon analyse des données et mon travail sur la sélection d'un modèle de classification en essayant de respecter au mieux la consigne.
Le Pipfile contient les librairies que j'ai utilisées pour mon analyse et mes scripts.

Les autres fichiers sont le jeu de données, le modèle utilisé pour la partie 2 (API), le jeu de données tests pour tester l'API, et la consigne.

Le fichier ExploData.ipynb est un notebook jupyter avec une première analyse des données et du feature engineering mais je n'étais pas sur de répondre à la consigne alors j'ai recommencé différemment.
Le fichier Basket.ipynb est le notebook principal pour la première partie de mon travail. Il contient les extraits du code fourni d'origine, et ma recherche de classificateur avec le processus de réflexion vis à vis de la consigne et des recherches associées.
Le fichier test.py est le script fourni à l'origine, avec des fragments de code pour la recherche de modèle, sans explication. Je l'ai déplacé en archive.
Le fichier app.py est le script pour lancer l'API. J'ai choisi Flask car c'est plus simple et direct pour ce travail. "python ./app.py" (commande pour lancer)
Le fichier call_api.py est le script que j'ai utilisé pour tester mon API.
