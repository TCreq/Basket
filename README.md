# 🏀 Basket - Test Technique MP Data

Ce repository contient l'ensemble des fichiers liés à ma contribution pour le test technique de MP Data.

## 📂 Contenu du Repository

- **`Pipfile`** : Contient les librairies utilisées pour mon analyse et mes scripts.
- **`ExploData.ipynb`** : Notebook Jupyter contenant une première analyse exploratoire des données et du feature engineering.
- **`Basket.ipynb`** : Notebook principal pour la première partie du travail, avec analyse de classification et réflexion sur la consigne.
- **`test.py`** : Script d'origine avec fragments de code pour la recherche de modèle (archivé).
- **`app.py`** : Script pour lancer l'API avec Flask.
- **`call_api.py`** : Script utilisé pour tester l'API.
- **Données et modèles** : Inclut le jeu de données, le modèle utilisé pour la partie API, et le dataset de test pour l'API.

## 📌 Utilisation

### Exécution de l'API
Lancer l'API Flask avec la commande :
```bash
python app.py
```

### Tester l'API
Utiliser le script `call_api.py` :
```bash
python call_api.py
```

## 📊 Analyse des données
L'analyse exploratoire est détaillée dans `ExploData.ipynb` et `Basket.ipynb`, avec des visualisations et une sélection de modèle de classification.
